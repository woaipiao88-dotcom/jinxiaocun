# v0.1.0 Release Notes

Initial public release of 管家婆风格进销存 V2.

## Highlights

- Lightweight Flask + SQLite inventory system.
- Plain JavaScript frontend with no build step.
- Product, customer, supplier, purchase, sales, inventory, movement, and backup workflows.
- Assistant-friendly search and summary APIs.
- LAN deployment guide for Windows environments.
- Basic automated tests and GitHub Actions CI.

## Notes

This release is intended for evaluation, local testing, and community feedback. Use demo data first. Do not commit real business databases, backups, or secrets.
